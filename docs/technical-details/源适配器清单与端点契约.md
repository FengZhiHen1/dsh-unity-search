## 网页引擎（family: web）

| id | 端点与要点 |
| --- | --- |
| bing | `GET https://www.bing.com/search?q=…&count=…`；HTML 解析结果块（标题/链接/摘要）；`timeRange` 映射 `filters=ex1:"ez1"` 类参数（实现期核实当前取值，标记 `missing evidence` 直至实跑） |
| ddg | `GET https://html.duckduckgo.com/html/?q=…`；HTML 解析；`timeRange` 映射 `df=d|w|m|y` |
| ddg-lite | `GET https://lite.duckduckgo.com/lite/?q=…`；极简 HTML，解析容错优先 |
| anysearch | `POST https://api.anysearch.com/v1/search`；JSON 问答式返回，`answer` 透传信封 |
| searxng | `GET {instance}/search?q=…&format=json`；实例列表来自 settings（公共实例参考 searx.be、searx.tiekoetter.com、search.inetol.net，默认空即不启用） |
| tavily | `POST https://api.tavily.com/search`；`Authorization: Bearer <key>`；返回 answer + results |
| exa | `POST https://api.exa.ai/search`；key 认证；支持 `numResults` 与日期过滤 |
| perplexity | `POST https://api.perplexity.ai/chat/completions`；答案在 message、citations 单独数组（可能仅 URL，信封 `items` 允许缺 title/snippet） |
| deepseek-official | `POST https://api.deepseek.com/anthropic/v1/messages`（Anthropic 兼容）；`x-api-key` + `Authorization: Bearer` + `anthropic-version: 2023-06-01`；body `tools: [{type: "web_search_20250305", name: "web_search", max_uses: 1}]`、model `deepseek-v4-flash`；解析 `web_search_tool_result` 块内 `web_search_result`（url/title/page_age），text 块 citations 的 `cited_text` 作 snippet；401 = key 失效 |
| keenable | 无 key：`POST https://api.keenable.ai/mcp`（MCP JSON-RPC `tools/call` → `search_web_pages`，取 `result.content[].text` 文本抽取 URL/标题，`result.isError` 为业务失败）；有 key：`POST https://api.keenable.ai/v1/search`（`KEENABLE_API_KEY`，额度更高）；双形态按凭据解析结果自动选择 |

端点知识来源：free-search 运行中代码（`references/open-source/dsh-free-search`）与 modsearch 调研记录；契约可抄、代码不搬。解析选择器与参数细节以实现期实跑为准（活体验证属实现期任务，登记于 TODO.md）。

## 学术源（family: academic）

| id | 端点与要点 |
| --- | --- |
| arxiv | `GET http://export.arxiv.org/api/query?search_query=all:…&start=0&max_results=…&sortBy=submittedDate`；Atom XML 解析（`entry`：title/id/summary/published/authors）；`sourceIds.arxiv` 取 id 尾段；条款要求约 3s 间隔（core 限速闸落实） |
| openalex | `GET https://api.openalex.org/works?search=…&per-page=…&mailto={contact}`；JSON；`sourceIds.doi` 取 `doi` 字段（去 `https://doi.org/` 前缀）；`extra`：`authorships` 取作者、`primary_location.source.display_name` 作 venue、`cited_by_count`；`timeRange` 映射 `filter=from_publication_date:` |
| crossref | `GET https://api.crossref.org/works?query=…&rows=…&mailto={contact}`；UA 带 contact 进礼貌池；`sourceIds.doi` 取 `DOI`；`extra`：`author`、`container-title`、`is-referenced-by-count` |
| pubmed | 两步：`GET https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esearch.fcgi?db=pubmed&term=…&retmode=json&retmax=…` 得 PMID 列表，`efetch.fcgi?db=pubmed&id=…&retmode=xml` 取题录（XML 解析）；url = `https://pubmed.ncbi.nlm.nih.gov/{pmid}/`；`sourceIds.pmid`；NCBI 匿名约 3 req/s（core 限速闸 1000ms 满足），条款建议带 `tool`/`email` 参数（复用 `contact`） |
| europepmc | `GET https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=…&format=json&pageSize=…`；JSON；`sourceIds.doi`/`pmid`；`extra`：`isOpenAccess`/`pmcid`/`journalInfo`；landing url 优先级 DOI > PMC > PMID；OA 全文/PDF 存在性入 `extra`，不自动抓取（有界原则） |

去重跨源主键 = DOI → arXiv id → 规范化 URL → 标题+首作者（规则归「检索核心与信封契约」）；pubmed 与 europepmc 的重叠条目经 DOI 或规范化 URL（`pubmed.ncbi.nlm.nih.gov/{pmid}/`）键在去重层合并。学术条目 `uncertainty` 恒定标注"仅元数据/摘要级"。

## 平台源（family: platform）

| id | 端点与要点 |
| --- | --- |
| github | `GET https://api.github.com/search/repositories?q=…&per_page=…`；匿名 60 req/h，配 `apiKeyEnv` token 提额；`extra`：`stargazers_count`/`language`/`updated_at` |
| stackoverflow | `GET https://api.stackexchange.com/2.3/search/advanced?site=stackoverflow&q=…&pagesize=…`；`extra`：`score`/`answer_count`/`is_answered` |
| hn | `GET https://hn.algolia.com/api/v1/search?query=…&hitsPerPage=…`（`search_by_date` 变体）；`extra`：`points`/`num_comments` |
| wikipedia | `GET https://{lang}.wikipedia.org/w/api.php?action=query&list=search&srsearch=…&format=json`；`lang` 来自 settings（默认 `zh`）；snippet 含 HTML 标记需剥除 |
| npm | `GET https://registry.npmjs.com/-/v1/search?text=…&size=…`；`extra`：`version`/`date` |
| v2ex | `GET https://www.v2ex.com/api/topics/hot.json` 拉热榜后本地过滤（title/content 含 query）——**非真搜索**，覆盖面限于当期热榜；条目 `uncertainty` 恒定标注"仅热榜过滤"；url = `https://www.v2ex.com/t/{id}`；snippet 取 content 截断 |
| bilibili | `GET https://api.bilibili.com/x/web-interface/search/all/v2?keyword=…`；headers 必须带 `referer: https://www.bilibili.com`；`data.code !== 0` 为业务错误；遍历 `data.result[].data[]` 取 `arcurl`/`title`（剥 HTML 标签）/`desc` |
| reddit | `GET https://old.reddit.com/search.json?q=…&limit=…&sort=relevance`；UA 带 contact 尾注（Reddit 条款要求）；`data.data.children[].data` 取 `url`/`title`/`selftext` |

## 失败语义

- 所有适配器把上游非 2xx、超时、解析失败归一为 `SourceOutcome.error`（code 词汇表归「检索核心与信封契约」），不抛出。
- 解析失败的判定：HTML/JSON 结构不含任何可识别结果块；空结果（结构正常、零条目）不是失败。
- 抓取类引擎（bing/ddg/ddg-lite）改版导致解析失效率高时，处置 = 引擎自然冷却 + 修复解析锚点发版；不做运行时自动切换实现。
