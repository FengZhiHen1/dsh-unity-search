# 借鉴地图

本文唯一拥有：外部项目实践 → 本设计承接点的索引与借鉴纪律。本文是**纯指针**：机制事实归各行所指的设计文档节（按节引用，不引整份文档）；出处以本文为准，各设计文档不再逐条内联维护。五仓库调研全文见本仓库 `references/dsh-检索插件调研与统一搜索方案-2026-09-09.md`；上游克隆在 `references/open-source/`（git 忽略树）。

借鉴纪律（需求文档非目标）：**契约可抄、代码不搬**——参考接口形状、端点知识、语义与教训，不复制上游实现。

## 明确不借鉴

- modsearch 的 CLI 子进程引擎形态（进程边界换跨 harness 复用，违背本插件 core/adapter 分层与零构建分发）。
- modsearch 的 X/Twitter 语料与登录态 CLI（需求文档非目标）。
- nature-academic 的 Semantic Scholar 全文兜底链（与 paper-search-mcp 同接口重复，且全文违背有界原则）——全文需求走 L3 逃生舱。
- paper-search-mcp 的 57 工具全量注入（L3 桥默认关、需要时开）。
- zotero-mcp 的一切写路径。
- yao-meta-skill 的"标准"（非官方；知识库 `agent/23` §0 警示，skill 约束一律以官方 spec 为准）。
